> The Siding Metaphor

In railway systems, a siding (측선/대피선) is a track branching off the main line where trains can stop, work, or be maintained without blocking ongoing traffic. tmux provides the switching and signals underneath, while Sidings gives you the master control room.

Main Line (본선)

Your main git branch stays clean and deployable. No collision, branch pollution, or uncommitted agent debris.

Sidings (측선)

Each agent conversation runs in an isolated Git worktree and managed branch with dedicated file isolation.

Trains (열차)

Claude Code, OpenAI Codex, and Antigravity (AGY) run concurrently as autonomous, independent engines.

Control Room (사령실)

A local web dashboard that shows turn statuses, commit history, and unified diffs in one live view.

> Key Capabilities

Solve the recurring headaches of coordinating concurrent CLI agents in raw terminal sessions.

Managed Worktree Isolation

Automatic branch creation, directory isolation, preview checkout, squash, and cleanup directly from the dashboard.

Bracketed Paste Safety

Large prompts and diffs stream via tmux paste buffers with settle delays, preventing buffer stalls and lost input frames.

Turn & Attention Detection

Distinguishes active, idle, and input-waiting states via provider hooks, screen inspection, and quiet windows.

Persistent tmux Sessions

Processes survive browser reloads or server restarts. Resume sessions seamlessly without interrupting agent execution.

In-Context Git & Diff Review

Inspect commit graphs, branch status, and file diffs side-by-side with live agent terminal output.

Spec-Driven Automation

Integrates GitHub Spec-Kit conventions (spec -> plan -> tasks -> implement) and headless batch workflows.

> Quickstart in 3 Steps

1

Prerequisites

Ensure Node.js 20+, Git, tmux, and at least one CLI (Claude Code, Codex, or AGY) are installed.

2

Run Sidings

Launch the dashboard with zero installation overhead:

npx @sidings-lab/sidings@latest
3

Orchestrate

Select your provider, open parallel worktrees, and review changes safely in context.
