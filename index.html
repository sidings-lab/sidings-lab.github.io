> Spec-Kit Workflow, Unified in Spec Cat

Spec Cat is a local development workbench for spec-driven teams. It follows GitHub Spec-Kit conventions and operationalizes the workflow: spec -> plan -> tasks -> implement -> review. In one interface, teams can write and edit specs, inspect Git graphs and diffs, run AI-assisted implementation with provider abstraction, and keep changes isolated through worktree-based preview/finalize flows. Built with Nuxt 3, Vue 3, TypeScript, and SQLite-backed spec search, Spec Cat helps teams move faster without losing structure or reviewability.
